# 墨洞(InkHole)文件传输 —— 项目计划与进度

> 最后更新：2026-07-15
> 一句话目标：把文件拖进桌面或手机上的「墨洞」，文件自动出现在另一台设备上。

## 总体设计

- 网络环境：**同一局域网**（mDNS 自动发现）；**跨网络**由「手动添加设备」承载——填对方 IP 直连，配合 Tailscale 等虚拟局域网即可异地互传
- 传输方式：**P2P 直连**（mDNS 发现/手动登记 + TCP 直传，无需自建服务器）
- 平台：**Windows / macOS / Android 三端互通**
- 加密：可选 AES-256-GCM 端到端加密（口令两端一致）

架构（两层解耦）：

```
   电脑A / Android                              电脑B / Android
┌──────────────┐    mDNS 自动发现     ┌──────────────┐
│ 墨洞桌宠/App  │ ──────────────────> │ 墨洞桌宠/App  │
│  (拖入/发送)  │    TCP 直连传输      │  (收到文件)   │
│              │    WHPP 协议         │              │
└──────────────┘    双向互传           └──────────────┘
   面子:桌面主窗口(QtWidgets)+桌宠(QML) / Compose UI
   里子:P2P引擎(mDNS+TCP直连+WHE2加密)
```

### 引擎第二轮
- [x] **WHE2 分块加密**：>32MB 加密文件走 4MB 分块流式 AES-GCM，块序号进 nonce+AAD（防篡改/重排），收发内存峰值恒定 4MB。≤32MB 保持 WHE1 整块。
- [x] **ACK 回执**：header 加 `want_ack`，接收方落盘后回 1 字节；发送方能感知解密失败/磁盘问题；向后兼容老版本。
- [x] **传输进度**：`on_progress(kind, name, done, total)` 回调，节流 0.25s；桌宠/Android 同步显示百分比。
- [x] **发送队列**：桌面拖 N 个文件串行排队，批量完成聚合提示"已吞入 k/N"。
- [x] **仅接收目标设备（trusted_only）**：只接受选中设备 IP 的连接，桌面/Android 设置页均可切换并持久化。
- [x] **多网卡/VPN**：mDNS 宣告全部本机 IPv4（默认路由优先），对端逐地址尝试连接。
- [x] **拒收 drain**：拒收时先消化对端已发数据（上限 8MB）再回执关闭，ACK_FAIL 不被 RST 冲掉。
