# iOS host

The Runner Xcode host is generated by Flutter in CI and locally with
`pwsh tool/bootstrap_flutter.ps1`. The checked-in `Podfile` installs the local
`InkHoleCore` pod, which links `native/ios/InkHoleCore.xcframework` and
force-loads the Rust FFI symbols used by `DynamicLibrary.process()`.
`tool/configure_ios_host.py` adds the required local-network usage description
and `_inkhole._udp` Bonjour declaration to the generated `Info.plist`.

Build the unsigned app on macOS with:

```bash
flutter pub get
bash tool/build_native_ios.sh
flutter build ios --release --no-codesign
```
